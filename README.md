# Описание проекта игры "Солитер"

Карточная игра "Солитер" на чистом JavaScript. Реализована игровая логика, 
перетаскивание карт, проверка правил и определение победы.

## Демо

[Ссылка на GitHub Pages / Vercel]

## Стек

- JavaScript (ES6+)
- HTML5
- CSS3

## Возможности

- Раздача карт и формирование игрового поля
- Перетаскивание карт между колонками
- Проверка правил: чередование цветов, порядок номиналов
- Перемещение карт в домашние ячейки
- Новая игра

## Что реализовано

- Игровая логика: колоды, масти, номиналы, правила перемещения
- Управление состоянием игры
- Обработка пользовательских действий
- Валидация ходов
- Адаптивная вёрстка под разные экраны

## Запуск

Открыть `index.html` в браузере
